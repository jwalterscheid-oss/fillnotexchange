# Keep the Tank

A static directory of propane **fill** stations (not exchange cages). Live: homepage, Denver directory, Sunday fills, and 100-lb / RV / forklift.

Project slug on GitHub is `fillnotexchange`; the repo and Pages URL are unchanged.

No framework. Data lives in JSON. HTML is generated by a short Python script.

## Preview

From this directory:

```bash
python3 -m http.server 8000
```

Open http://127.0.0.1:8000/ — do not expose a public tunnel.

Rebuild after any JSON change:

```bash
python3 build.py
```

## How to add a listing

1. Open `data/listings.json`.
2. Copy an existing object in `listings`.
3. Give it a unique `id` (slug, lowercase, hyphens).
4. Set `city_slug` to an existing city in `cities` (or add a city first).
5. Fill only facts from a public page or a phone call you made. Use `null` or the string `"unknown"` when you do not know.
6. `service_type` must be exactly one of: `fill`, `exchange`, `both`.
7. Set `last_verified` to the date you checked (YYYY-MM-DD).
8. Put the canonical public URL in `source`. Extra URLs go in `source_extra`.
9. Run `python3 build.py`.

Do not invent a phone, hours, tank size, recert, or RV capability. Do not paste a chain locator dump. Do not publish a price as fact.

### Field notes

| Field | Rule |
|---|---|
| `hours` | Object with `mon`…`sun`. Each value is a range string, `"closed"`, or `null`. |
| `propane_hours_note` | Store hours ≠ attendant hours. Say so. |
| `fills_rv_onboard` | `yes` / `no` / `unknown` / `n/a` |
| `recertifies` | Only `yes` if the shop itself says they certify/requalify. Reviews are not enough. |
| `pay_at_pump` | `yes` / `no` / `unknown` |

## How to add a city

1. Append an object to `cities` in `data/listings.json`:

```json
{
  "slug": "colorado-springs",
  "name": "Colorado Springs",
  "metro_name": "Colorado Springs",
  "state": "CO",
  "blurb": "One sentence about this city’s fill vs cage problem."
}
```

2. Add listings with `"city_slug": "colorado-springs"`.
3. Run `python3 build.py`. That writes `colorado-springs.html` and adds a link on the homepage.

Slug becomes the filename. Keep it lowercase, hyphens only.

## What this site will not do

- List an exchange cage as a refill.
- Rank “best propane.”
- Affiliate links on night 0.
- DIY fill instructions.
- Home-delivery 500-gallon tanks mixed into portable-cylinder rows.
